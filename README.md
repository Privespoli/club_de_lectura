# 📚 Reto 2: Gestor para el Club de Lectura

Pequeño programa desarrollado en Python para gestionar el catálogo de libros de un club de lectura, permitiendo llevar un seguimiento de las lecturas pendientes, en curso y terminadas.

## 🚀 Funcionalidades del Programa

El sistema cumple con todos los requisitos obligatorios del reto:
1. **Catálogo Inicial:** Inicia con un catálogo predefinido de al menos cuatro libros con su título, autor/a, género y estado de lectura.
2. **Mostrar Catálogo:** Muestra de forma clara y ordenada toda la información de los libros registrados.
3. **Añadir Libro:** Permite incorporar nuevos títulos al catálogo solicitando título, autor/a y género (asignando automáticamente el estado *"pendiente"*).
4. **Búsqueda por Estado:** Permite consultar los libros filtrando según su estado actual (*pendiente*, *leyendo* o *terminado*), manejando casos en los que no haya coincidencias.
5. **Resumen del Club:** Calcula y muestra estadísticas generales (número total de libros, pendientes, en lectura y terminados).

---

## 🛠️ Requisitos Técnicos (Python)

El código implementa los siguientes conceptos de programación:
* **Variables** para almacenar datos y resultados.
* **Listas** para guardar los elementos del catálogo.
* **Diccionarios** para representar la información detallada de cada libro.
* **Estructuras condicionales** (`if`, `elif`, `else`) para la toma de decisiones y filtros.
* **Bucles** (`for` / `while`) para recorrer listas y repetir acciones.
* **Funciones propias** para modularizar el código y evitar la repetición de instrucciones.
